# 使用说明

## 从照片开始

1. 在「创作台」点击「选择图片」，选取手机相册中的图片。也可以点击花朵、狐狸、咖啡示例体验转换。
2. 查看拼豆预览，通过「原图」切换对比。
3. 设置尺寸、图片类型和颜色数量，等待预览更新后点击「生成图纸」。

| 设置 | 选择建议 |
| --- | --- |
| 29 × 29 | 一块底板，适合小挂件和简单图案 |
| 58 × 58 | 四块底板，适合保留更多主体细节 |
| 87 × 87 | 九块底板，豆子用量和制作时间更多 |
| 插画 / 照片 / 像素 | 按原图类型选择取样方式 |
| 8 / 16 / 24 色 | 限制颜色数量，降低备料难度 |
| 不限 | 在所选色卡范围内保留更多颜色 |

「更多设置」内可切换 MARD / Hama 色卡、完整保留或居中裁切，并移除外围相连的白底。透明区域不计入用豆量。成品尺寸按 5mm 豆估算。

## 只拼人物、宠物或物品

1. 选图后点击「提取主体」，页面会自动开始识别。
2. 检查结果。灰色棋盘区域表示不生成豆子的背景。
3. 遗漏部分用「补回」涂回；多余背景用「擦除」移除。支持三档画笔和最多 8 步撤销。
4. 自动结果不合适时，用「手动圈选」沿主体画闭合轮廓。
5. 按住「看原图」比较，选择是否居中，点击「使用这个主体」。

应用后可继续修整或恢复背景。更换图片会清除上一张的主体选区。复杂毛发、相近背景或多主体需要单独选择时，可能需要人工修整。

微信原生模型推理需要基础库 2.30.0+，请用真机预览。开发者工具模拟器不支持该接口。失败时可展开「查看原因」，重试自动识别，或先用手动圈选。

## 直接使用样板

底部「拼豆样板」内有 640 份图纸。支持动物、花草、游戏、水果、食物、甜点、表情、小物分类，以及关键词搜索、「新手」筛选和「可爱挂件」合集。列表每批加载 24 份，可继续加载更多。

点击样板查看成品、色数、豆子总数、底板和来源。点击「使用图纸」直接进入制作页，无需重新识图配色。

## 看图纸与记录进度

- 切换「图纸 / 成品」查看网格或拼豆效果。
- 缩放按钮或双指手势放大，拖动查看细节；开启「色号」查看完整代码。
- 大图按 29 格底板切换分区，每 5 格有加粗线辅助计数。
- 点击用豆清单中的颜色高亮对应格子，也可搜索色号。
- 完成一种颜色后打勾，进度按已完成豆子数量计算；重新打开会恢复。
- 「复制」可复制用量清单，方便备料。

## 导出与保存

「导出图纸」提供色号图纸和成品效果两种 PNG。色号图纸包含坐标、完整色号、底板分界与用豆清单。微信保存可能需要相册权限；H5 使用浏览器下载。CC BY 图案会附带作者、来源、许可和修改说明。

生成图纸后自动保存到「我的作品」，可重命名、按进行中/已完成筛选、继续制作或删除。记录仅在当前设备保留最近 20 份；更换设备或清理数据前请导出。

## 常见问题

**选图后仍在处理：** 大照片需要解码和配色；页面提供超时错误与重试，也可换图恢复。

**颜色与实体豆不一致：** 先确认色卡品牌，屏幕、照片光照和豆子批次也会影响观感。

**主体缺了一部分：** 用「补回」修整，或手动圈选。自动识别无法保证每张图片都准确。

**作品不见了：** 确认是否同一设备、浏览器或微信环境；当前没有账号同步功能。
