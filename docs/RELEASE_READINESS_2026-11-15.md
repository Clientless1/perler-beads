## 本轮修复

| 问题 | 处理结果 |
| --- | --- |
| 裁剪双指缩放偏离触点，两指一起拖动没有效果 | 以手指中点作为缩放锚点，支持两指平移，边界不露空白 |
| 原生触摸测量途中进入禁用状态，后续触摸可能永久失效 | 清理待处理手势和事件队列，解除禁用后可重新操作 |
| 游客收藏页返回登录后再次自动跳登录 | 改为明确登录按钮，用户可以退出登录页 |
| 切换账号后残留旧图纸详情或旧 Pro 权益 | 清理详情与权益状态，过期接口响应不覆盖当前账号 |
| 损坏的本机会话导致启动失败，存储失败导致半登录状态 | 校验会话结构，成功写入本机后才切换账号 |
| 断网无法退出账号 | 本机会话仍会清理，远端失败明确提示 |
| 本机写入失败却显示已保存 | 独立记录保存结果，失败显示待保存本机并可重试 |
| 编辑保存失败直接退出，可能丢失刚画的格子 | 保留编辑内容，保存成功才关闭编辑器 |
| 保存、检测、PDF 等迟到结果在换账号/卸载后继续执行 | 通过账号和页面任务版本校验丢弃迟到结果，停止排队请求 |
| 服务未开启仍能进入购买，App 付款没有后续动作 | 未启用或平台不支持时收起购买/付款入口；已有权益和订单保留 |
| App 工程文件没有实现却显示成功或解析 undefined | 收起 App 导入/备份入口，内部调用明确返回未支持；微信和网页保留 |
| 登录页同步说明与实际自动保存行为不一致 | 明确登录后图纸和进度自动同步 |
| 发布检查全 PASS 容易被理解为可提审 | 报告明确给出 readyForSubmission=false，并列出未解决事项 |

回归涉及真实页面脚本、Vue 响应式、触摸几何、模型 Worker 与存储逻辑。网络/原生接口替身测试不能代替真实微信或 Android 设备。

## 正式上架前必须完成

1. **接通微信官方内容安全。** 当前选图调用 `src/utils/contentSafety.js` 本地模型。后端旧版 `wechat.mjs` 有官方接口实现，但正常启动的 `platform/index.mjs` 没有挂载旧检测服务，作品创建/更新/迁移和文本发布仍没有实际官方检测闭环。须覆盖审核要求的场景，并验证违规、待复核、超时、服务失败均不能绕过。仅添加色情模型不足以解决已收到的审核意见。
2. **改用微信允许的正式 HTTPS 域名。** 当前微信构建实际使用 `https://1.92.110.111`。需要真实备案域名、有效证书，以及微信后台合法 request/download 域名配置。APK 能访问 IP 不能证明微信正式版可访问。
3. **补真实运营信息。** 隐私页面仍有运营主体、联系方式和服务条款待填写的文案；不能替用户编造。微信后台隐私保护指引、服务类目、实际数据用途必须对应当前云端功能。
4. **完成候选发布包真机验收。** 至少 Android APK、Android 微信、iPhone 微信各跑选图/取消重选、主体修整、裁剪、87 格图纸、编辑、相册授权拒绝后恢复、保存重开、弱网和账号切换。记录冷启动耗时、内存、手势响应及崩溃日志；本轮桌面触屏测试不代替这些项目。

当前免费版没有可验证的真实购买闭环。购买入口已收起，若后续开放收费，需单独验收支付资质、真实回调、到账、取消和退款；本轮未付款。Android 工程文件导入/备份仍未实现，已从该平台界面收起。
