# 后端已独立拆分 · 2026-11-12

独立项目位于同级 `../perler-beads-backend/`，后端文档与部署脚本随该项目交付。

- 客户端只保留 `src/`、小程序构建与前端测试，不包含后端、管理台和部署目录。
- 后端包含 API、管理台、PostgreSQL 迁移、图纸目录、PDF、Docker/systemd 配置。
- 后端不读取客户端源码，依赖的色卡和通用计算已放到后端 `lib/`；图纸数据在 `catalog/`。
- 服务器只运行独立后端。`/` 返回服务信息，`/admin/` 提供运营管理台；客户端静态文件与本地模型不对外托管。
- 微信小程序在本机构建为 `dist/build/mp-weixin/` 并通过微信开发者工具上传。
- 本地 H5 用于手机尺寸开发验证，不作为服务器部署产物。

旧部署与历史文档仅为过程记录，新的安装和发布以独立后端 README 为准。
