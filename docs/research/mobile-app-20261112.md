# 手机 App 界面调研与实现 · 2026-11-12

证据取自 Apple App Store 公开手机截图与应用说明，通过 Apple iTunes Search API 查询；未安装付费 App，未声称完整试用。这次研究对象是手机应用界面，未采用网页布局。

|App|手机截图可见的设计|本次采用|
|---|---|---|
|[Perlypop](https://apps.apple.com/us/app/id1450794449)|照片转换画布居上，编辑参数在下；编辑与 PDF 导出分开|先选照片，再显示调整工具；预览在设置上方|
|[Beads Creator](https://apps.apple.com/us/app/id1235585928)|画布占主要空间，色卡与编辑工具靠近底部；材料清单为独立界面|图纸作为结果页主体，材料按需展开，导出用底部面板|
|[ibis Paint X](https://apps.apple.com/us/app/id450722833)|手机画布边缘集中放工具，少量快捷控件，避免在画布上铺满文案|画布外显示状态，工具动作短标签|
|[Photomator](https://apps.apple.com/us/app/id1444636541)|单张照片为焦点，针对当前工具显示参数，主体选择就近出现|选图后突出“只拼主体”，高级设置折叠|

研究原始 JSON、手机截图与接触表在本机 `output/playwright/native-research/`，只用于研究，不进入产品或小程序包。

交互落地：

1. 四个稳定底部入口：做图、图纸、作品、我的。首页仅保留选照片、按需新手步骤、三个试用样板和继续作品。
2. 引导点开才展开；不增加首次弹窗，避免打断操作。
3. 选图后显示流程位置、去背景入口、实时预览、常用参数与固定生成按钮。
4. 图纸库首屏仅搜索、主题与图纸；分类、排序和新手条件放进筛选面板。
5. 我的页以账号、作品/收藏/豆盒为主，权益缩成一行，订单与支持在列表中。
6. 作品空态区分未登录与无作品；图纸材料可收起。

保留现有本地检测、主体推理、配色、云端保存和权限边界；不复制其他 App 的品牌、美术或素材。


## 用户提供的同行截图（二次重构）

五张手机截图展示了个人页、画布尺寸、双列图库、深色成品预览及全屏精修。独立实现了三步创作、16–87 格自定义正方形、可旋转的 Canvas 成品模拟、深色编辑台、工具箱与逐色开拼。未引入截图中的付费标记、会员数据、作者头像或角色图纸。

## 图纸题材与来源

查阅了拼豆图库、官方 Perler 图纸及社交平台检索结果（检索原始摘要在本地 output/research/product-search.json）。检索不足以验证“抖音爆款”的浏览和互动数据，也不等于获得转载权。当前按萌宠、甜品、花草、小物题材扩充，未给新图纸添加虚构热度、点赞或作者信息。

新增 52 份精细萌物来自 [Noto Emoji SVG](https://github.com/googlefonts/noto-emoji/tree/22e564626297b4df0a40570ad81d6c05cc7c38bd/svg)，SVG 目录明确使用 Apache 2.0。后端保留原图、目录许可、NOTICE、版本和 SHA-256，导出保留作者/来源/修改声明。固定 58 格、最多 20 色；与之前 29 格 Twemoji 为不同画风版本，不当作 52 个此前完全不存在的题材来宣传。可授权收录的创作者作品仍可通过管理台上架。
