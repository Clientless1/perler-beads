# 使用说明

当前为 2.2.0 手机工作台版。照片检测、主体提取和图纸生成在设备完成；登录后图纸、作品名称、进度、豆盒、订单和工单保存到云端。游客可以试用照片转换和 PNG 导出，游客作品自动保存在当前设备（最多 20 份），登录后可迁移；清理小程序数据前请导出工程备份。

通过底部「我的」或作品库「登录云端」注册/登录。旧版本设备里最多 20 份作品不会自动上传；账号页显示「迁移到我的云端」时，确认登录账号后点击即可，重复点击不会产生副本，本机旧记录保留。

## 账号、豆盒与客服

- 「我的豆盒」选择 MARD / Hama，填写色号库存和每颗成本（分）。保存后换设备也能读取；图纸页显示缺豆与预计成本。
- 「创作升级」展示服务端配置的套餐，创建订单后支付。开发环境的「测试付款」不会扣真实款，不计入经营收入。真实微信登录/支付需要运营方完成接入。
- 「咨询与定制」可以创建使用咨询或图纸定制工单，并查看客服回复、补充需求。员工内部备注不会向客户显示。
- 可以修改昵称和密码、退出账号；忘记密码目前通过客服核验后由管理员重置。

## 从照片开始

1. 在底部「做图」点击醒目的「选择照片」，选择相册图片或拍照。也可以点击奶白兔、小熊、薄荷甜筒示例体验转换。
2. 等待本机图片检测，通过后查看拼豆预览，通过「原图」切换对比。可取消检测；检测失败可重新选图，命中违规仅提示「内容含违规信息」。照片不会上传。
3.「整理照片」里去背景、旋转、镜像或裁剪；下一步「尺寸配色」选格数、色卡和颜色数量；最后「确认开拼」核对效果与用量，生成图纸。

| 设置 | 选择建议 |
| --- | --- |
| 29 × 29 | 一块底板，适合小挂件和简单图案 |
| 58 × 58 | 四块底板，适合保留更多主体细节 |
| 87 × 87 | 九块底板，豆子用量和制作时间更多 |
| 插画 / 照片 / 像素 | 按原图类型选择取样方式 |
| 8 / 16 / 24 色 | 限制颜色数量，降低备料难度 |
| 不限 | 在所选色卡范围内保留更多颜色 |

「尺寸配色」支持 16–87 格自定义正方形，MARD / Hama 色卡及外围白底去除。「整理照片」中的裁剪可选原比例、正方形、3:4、4:3，并调整位置。透明区域不计入用豆量。成品尺寸按 5mm 豆估算。

## 只拼人物、宠物或物品

1. 选图后，在预览图上方点击「智能去背景」卡片，页面会自动开始识别。
2. 检查结果。灰色棋盘区域表示不生成豆子的背景。
3. 遗漏部分用「补回」涂回；多余背景用「擦除」移除。支持三档画笔和最多 8 步撤销。
4. 自动结果不合适时，用「手动圈选」沿主体画闭合轮廓。
5. 按住「看原图」比较，选择是否居中，点击「使用这个主体」。

应用后可继续修整或恢复背景。更换图片会清除上一张的主体选区。复杂毛发、相近背景或多主体需要单独选择时，可能需要人工修整。

微信原生模型推理需要基础库 2.30.0+，请用真机预览。开发者工具模拟器不支持该接口。失败时可展开「查看原因」，重试自动识别，或先用手动圈选。

照片内容检测优先使用微信原生推理；开发者工具模拟器或原生推理不可用时，在后台 Worker 中用自带模型和本地 WASM 完成检测（不支持时使用分段 CPU），仍可选择照片和生成图纸。首次加载图片检测分包需要网络，照片不会上传；首次准备需多等待几秒，检测期间可查看进度或取消；短暂调整参数不会重复加载模型，同次打开内重复选择相同图片可复用实际内容检查。本地识别可能误判或漏判，详情见[图片检测说明](LOCAL_IMAGE_SAFETY.md)。

## 直接使用样板

底部「灵感」通过云端获取图纸；当前有 938 份，实际上架数量由运营维护，部分图纸可设置为 Pro 专享。支持动物、花草、游戏、水果、食物、甜点、表情、小物分类，以及关键词搜索、「新手」筛选和「萌趣」「上新」「原创」「收藏」与治愈萌宠/甜品小物合集。列表每批加载 24 份，可继续加载更多。

点击样板查看成品、色数、豆子总数、底板和来源。登录后点击「使用图纸」进入制作页，无需重新识图配色。

## 看图纸与记录进度

- 切换「图纸 / 成品」查看网格或拼豆效果。
- 开启「显示色号」查看完整代码，保持当前缩放和位置，不自动放大。
- 加减按钮与双指手势共用 100%～800% 的缩放范围，放大后可拖动查看细节；点击「看全图」恢复完整图纸和居中位置。
- 大图按 29 格底板切换分区，每 5 格有加粗线辅助计数。
- 点击用豆清单中的颜色高亮对应格子，也可搜索色号。
- 完成一种颜色后打勾，进度按已完成豆子数量计算；重新打开会恢复。
- 「复制」可复制用量清单，方便备料。
- 「逐格编辑」支持画笔、橡皮、取色、连通填色、全图换色、撤销和重做；点「保存编辑」后更新云端图纸。
- 每块底板可单独标记完成。5mm / 2.6mm 可切换；材料费只是按库存成本估算。
- 「尝试库存配色」使用有库存的颜色重新匹配，会改变效果；缺豆数量仍需检查。

## 导出与保存

「导出图纸」提供色号图纸和成品效果两种 PNG。色号图纸包含坐标、完整色号、底板分界与用豆清单。微信保存可能需要相册权限；H5 使用浏览器下载。CC BY 图案会附带作者、来源、许可和修改说明。

登录后生成图纸自动保存到「我的作品」。普通用户可存 100 份，Pro 可存 2000 份。可重命名、继续制作或删除；另一设备修改同一作品时，会提示重新打开，避免覆盖新版本。网络失败会显示待保存与重试。

微信小程序和网页的「备份工程」导出可编辑 JSON，在账号页「导入工程文件」恢复为一份新作品。「分页 PDF」提供彩色/黑白色号 A4，按 29 格底板分页、包含用豆清单和 50mm 校准线；打印选择 100% 实际大小，关闭适应页面。每次新打印任务扣 1 次打印权益，Pro 有效期内无需扣次数，同一任务重试不重复扣减。

## 常见问题

**选图后仍在处理：** 大照片需要解码和配色；页面提供超时错误与重试，也可换图恢复。

**颜色与实体豆不一致：** 先确认色卡品牌，屏幕、照片光照和豆子批次也会影响观感。

**主体缺了一部分：** 用「补回」修整，或手动圈选。自动识别无法保证每张图片都准确。

**作品不见了：** 确认当前登录账号、云端服务是否可用；旧版本作品需在原设备登录后主动迁移。游客生成的图纸自动保存在本机（最多 20 份）；尚未生成图纸的照片调整只保留在当前会话，请勿刷新页面。


## 手机工作台（2.2.0）

- 「逐格编辑」进入浅色全屏工作台，默认画笔。单指连续涂画，双指缩放和移动；也可切换「移动」工具单指拖动。支持 1 / 3 / 5 格笔触、橡皮、取色、连通填色和整图换色，每一笔作为一步撤销。支持 100%～1000% 缩放，点击百分比回到全图，最多 30 步撤销/重做。「更多」提供旋转、镜像、翻转与清理孤点。点「保存」后更新图纸，未保存退出会询问。
- 「成品预览」提供原豆、轻烫留孔、常规圆烫、平烫封孔、像素方烫五种外观，可单指转动、双指缩放（50%～400%）、自动旋转、复位并保存当前效果 PNG。模拟图不代表实际熨烫温度或时间。
- 「开始拼」进入逐色模式，只高亮当前色号；拼完一色，标记完成并进入下一色，进度保存后可从作品库恢复。底板与颜色进度分开。
- 「第一次拼豆」教程覆盖选图、尺寸色卡、备豆、逐色拼制与安全熨烫。
- 精细萌物增加 52 份 58 格图纸，Noto Emoji SVG / Google / Apache 2.0。每份图纸保留来源；这批不标为抖音爆款，未取得社交平台作者授权的作品不直接收录。


## 相册式裁剪（2026-11-13）

在「整理照片」点击「裁剪构图」。拖四角调整选区，拖照片调整位置，双指放大照片；九宫格帮助对齐。可选自由、原图、1:1、3:4、4:3、9:16。「完成」应用一次裁剪，「取消」保留之前的结果，「重置裁剪」恢复整张照片。旋转与镜像在制作页操作；提取主体时优先保留完整轮廓，恢复整张照片后可再裁剪。


### 2026-11-15 功能开放范围

- 基础做图和 PNG 导出免费。支付服务未启用时，会员页不提供购买操作；已有权益可以继续使用。当前 Android App 尚未支持付款，因此不展示付款按钮。
- 工程文件导入、备份目前仅在微信小程序和网页提供，Android App 已收起对应入口，可使用 PNG 导出。
- 编辑保存失败会保留编辑内容，修复网络或存储问题后再次点保存；只有保存成功才退出编辑。
